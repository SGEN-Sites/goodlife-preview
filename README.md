# Good Life Collective: redesign preview

Design preview of a full redesign of [gotogoodlife.com](https://gotogoodlife.com/) (Good Life Collective: Rochester,
Buffalo, Canandaigua and Batavia, NY + Astoria, OR), built with Good Life's own brand, words, stores and live menus.

**Preview:** https://sgen-sites.github.io/goodlife-preview/

- Every page carries `<meta name="robots" content="noindex, nofollow">`, so this preview stays out of search engines.
- Menus show the five stores' real products as captured from gotogoodlife.com on 2026-11-18. The bag and checkout are a
  **clearly labelled demo**: nothing is sent and no payment is taken.
- `sitemap.xml` lists the production URLs (gotogoodlife.com) the structure is designed for.
- Static site (HTML + CSS + vanilla JS). Generated imagery provenance is kept with the build source, not here.

Design preview, not the live site.
